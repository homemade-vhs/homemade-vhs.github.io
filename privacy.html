Privacy policy

Last updated October 8, 2026

Stream Desk is a private dashboard used by the SuperMega team during the SuperMega YouTube channel's live streams. This page explains what information it uses and what it does with it.

What it reads from YouTube

Stream Desk signs in with Google as the SuperMega channel and uses the YouTube Data API to read, for that channel's own live streams:

  • live chat messages, with each sender's public display name and whether they are a member, moderator or the channel owner
  • Super Chats, Super Stickers, memberships and gifted memberships, including amounts and currencies
  • public stream statistics: viewers, views and likes

It does not read anything from anyone else's channel or Google account.

What it can do on YouTube

Only when a host clicks to do so, Stream Desk can send a chat message, delete a message, time out or ban a user, and start or end a poll in the channel's own live chat. It never does any of these by itself.

How the information is used

The information is shown on the dashboard so the hosts can follow chat and thank supporters during the stream, and it is used to make an end-of-stream summary for the team. Nothing else.

Where it is stored

Everything is stored only on the computer in our stream room that runs Stream Desk. This includes chat and Super Chats from each stream, and the Google sign-in token. It is not uploaded to any other server or cloud service. Besides YouTube, it contacts only a currency exchange rate service, to convert Super Chat amounts to US dollars, and GitHub, to check for Stream Desk updates. No personal information is sent to either.

Sharing

We do not sell, share, or transfer this information to anyone, and we do not use it for advertising.

Google API Services

Stream Desk's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Stream Desk uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access and deleting data

The channel owner can remove Stream Desk's access at any time from Google Account permissions. Saved stream data can be deleted by removing it from the Stream Desk computer.
